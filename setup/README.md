# Cơ sở dữ liệu Website chia sẻ công thức nấu ăn

## 1. Giới thiệu

Thư mục này chứa các tài liệu phục vụ việc thiết lập cơ sở dữ liệu cho đồ án website chia sẻ công thức nấu ăn sử dụng ASP.NET.

## 2. Danh sách tệp

- `database.sql`: Script SQL dùng để tạo cơ sở dữ liệu và các bảng.
- `SoDoCoSoDuLieuWebsiteNauAn.drawio`: Sơ đồ thiết kế cơ sở dữ liệu.

## 3. Công cụ sử dụng

- Microsoft SQL Server.
- SQL Server Management Studio (SSMS).
- diagrams.net để xem sơ đồ cơ sở dữ liệu.

## 4. Hướng dẫn cài đặt

1. Cài đặt Microsoft SQL Server và SQL Server Management Studio.
2. Mở SSMS và kết nối đến SQL Server.
3. Mở tệp `database.sql` bằng SSMS.
4. Chọn **Execute** để chạy các lệnh SQL.
5. Kiểm tra cơ sở dữ liệu `WebsiteNauAn` và các bảng đã được tạo thành công.

## 5. Lưu ý

Tên cơ sở dữ liệu và cấu trúc các bảng phải thống nhất với cấu hình và mã nguồn của dự án ASP.NET.
