# BÁO CÁO TIẾN ĐỘ TUẦN 02

## 1. Công việc đã thực hiện

- Phân tích yêu cầu của website chia sẻ công thức nấu ăn.
- Xác định các chức năng chính của hệ thống.
- Tìm hiểu mô hình ASP.NET Core MVC.
- Tìm hiểu cách tổ chức cấu trúc dự án.
- Phân tích các đối tượng dữ liệu cần lưu trữ.

## 2. Kết quả đạt được

- Xác định được các chức năng chính của website.
- Xác định được các đối tượng dữ liệu cơ bản.
- Có định hướng xây dựng cơ sở dữ liệu cho hệ thống.
- Tiếp tục hoàn thiện Repository trên GitHub.

## 3. Công việc tuần tiếp theo

- Thiết kế cơ sở dữ liệu.
- Tạo project ASP.NET Core MVC.
- Kết nối cơ sở dữ liệu SQL Server.
- Xây dựng giao diện trang chủ.

## 4. Khó khăn

- Chưa quen với ASP.NET Core MVC.
- Cần tìm hiểu thêm về Entity Framework Core và SQL Server.

## 5. Hướng giải quyết

- Tìm hiểu tài liệu ASP.NET Core MVC.
- Thực hành từng chức năng nhỏ.
- Tham khảo tài liệu và ví dụ phù hợp.
